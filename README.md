🛡️ IR Prohori

A security-first AI knowledge assistant for digital safety in Bangladesh.

IR Prohori is a bilingual (Bangla + English) AI assistant that helps young people in Bangladesh find trusted information on online safety, cyberbullying prevention, and responsible digital citizenship.


🎯 About

Developed by Md Iftiur Hossen Riyad at the Department of Cyber Security Engineering, University of Frontier Technology, Bangladesh (UFTB).

- 🔒 Security-first design
- 🌐 Bilingual (Bangla + English + Banglish)
- 🤖 RAG-based AI with verified sources
- 🧠 Cross-chat memory
- 📱 Mobile responsive

✨ Features

| Feature | Description |
|---|---|
| 🔐 Authentication | Login, Register, Forgot Password |
| 💬 Chat History | Persistent chat list with delete |
| 🧠 Memory | Remembers user facts across chats |
| 🤖 Hybrid AI | Greeting, Verified, General, Sensitive responses |
| 🌐 Language Match | Bangla → Bangla, English → English |
| 📄 Source Display | Shows which documents answers come from |
| 🎨 DeepSeek-style UI | Modern dark theme |
| 📱 Mobile Responsive | Works on all screens |

🛠️ Tech Stack

Backend:
- FastAPI
- LangChain
- ChromaDB (Vector Database)
- Groq API (LLM)
- Hugging Face Embeddings

Frontend:
- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage

🚀 Getting Started

Prerequisites

- Python 3.10+
- Groq API Key (Get one free at https://console.groq.com/)

Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/iftiurhossenriyad/IR-Prohori.git
   ```
